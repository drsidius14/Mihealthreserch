# Mi Health Research V17 — сборка и проверка

Цель: собрать следующий тестовый вариант из неизменённого оригинального APK, исправить подтверждённые дефекты русификации, проверить таблицу ресурсов/DEX/подпись и выполнить реальный запуск на эмуляторе Android 15.

## Что исправляется
- Ошибка `hospital_sleep_need_opened_tips`: очищаются `.text` и `.tail` вложенных XML-узлов перед заменой styled string.
- Русские подписи карточек и диалога Mi Fitness применяются только по allow-list строк DEX.
- Короткие подписи кнопок/заголовков снижают вероятность наложения на исходной геометрии.
- Сохранение оригинального APK, `classes2.dex`, native libs, assets и всех нецелевых ресурсов проверяется workflow.
- В workflow используются APK, закоммиченные в ветку, а не отсутствующие `v10-build` и старый artifact run.
- Сборка V17 для диагностики загружается отдельным artifact даже если позднее независимый audit провалится; финальный artifact V17 публикуется только при прохождении статических и emulator gates.
- Emulator gate снимает UIAutomator XML, screenshots и `adb logcat`, проверяет запуск/базовый режим и сравнивает вкладки с оригиналом и V8.

## Отправка с телефона
1. Распаковать этот ZIP в Download.
2. В Termux выполнить команду из `V17_TERMUX_COMMAND.txt`.
3. Открыть GitHub Actions и дождаться завершения `V17`.

Команда не собирает APK на телефоне: она отправляет проверенные исходники и контрольные APK в отдельную ветку `v17-build`. APK строит GitHub Actions. Не считать результат успешным, пока не завершились оба задания и не появился artifact `XiaomiHealthResearch_V17`.

## Ограничения
Эмулятор проверяет запуск, crash logs и базовые экраны, но не заменяет реальный телефон с Xiaomi Account/Mi Fitness/HealthKit. APK подписывается тестовым ключом, поскольку оригинальный закрытый ключ Xiaomi недоступен; онлайн-авторизация Xiaomi этим не доказывается.
