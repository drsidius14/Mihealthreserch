# Xiaomi Health Research V17.03 — пакет исходников для GitHub Actions

Этот пакет **ничего не загружает самостоятельно**. Он добавляет локальные исправления в существующий клон `drsidius14/Mihealthreserch`; отправка на GitHub выполняется только отдельной командой Termux, которую запускает пользователь.

## Что меняется
- Создаётся отдельный workflow `.github/workflows/v17_03.yml` на основе проверенной конфигурации V17.
- Исправляется запуск Android 15 smoke test: тело сценария явно передаётся Bash, потому что тест использует Bash-конструкции.
- В DEX-словарь добавляются русские варианты двух китайских заголовков с экранов.
- Проверка вкладок становится строгой: пустая вкладка приводит к ошибке теста, а не только к диагностической записи.
- Исходный workflow `.github/workflows/v17.yml` сохраняется без изменения.
- Не меняются манифест, разрешения, intent-фильтры и логика приложения.

## Ограничения
Это кандидатная подготовка V17.03, а не готовый APK. Сборка должна пройти GitHub Actions. Успех нельзя объявлять до появления артефакта и runtime-отчёта. APK будет пересобран и заново подписан workflow; при другой подписи установка поверх предыдущей версии может не пройти — для диагностики может потребоваться удалить старую версию перед установкой.
