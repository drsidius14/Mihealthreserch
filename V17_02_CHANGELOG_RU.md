# V17.02 — исправление сравнения Smali после Apktool

## Причина

В прогоне V17.01 декомпиляция и повторная сборка изменили представление некоторых полей: например, `.field public static c:Z = false` превратилось в `.field public static c:Z`. Для JVM эти формы эквивалентны: `false` — значение по умолчанию для `boolean`, поэтому поле может быть представлено без явного инициализатора. Из-за этого строгий построчный компаратор ошибочно остановил проверку до упаковки APK и Android runtime-тестов.

## Изменение

Компаратор разрешает только узкую нормализацию явных JVM-значений по умолчанию в декларациях `.field`: `false`, нулевые числовые значения и `null` для ссылочных полей. Имя, тип, модификаторы и комментарии должны совпадать. Ненулевые/ненулевые-не-значения-по-умолчанию, строки, инструкции, ветвления, состав файлов Smali и остальные различия по-прежнему проверяются строго.

Добавлены регрессионные тесты на разрешённые дефолтные значения и отклонение `true`, ненулевого числа и строкового значения.

## Границы

Это исправление верификатора, а не утверждение, что APK уже собран или работает. Сборка, подпись, установка и Android runtime-проверки считаются пройденными только при наличии успешного GitHub Actions запуска и отчёта.
