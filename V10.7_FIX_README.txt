Xiaomi Health Research V10.7 — исправление целостности ресурсов

Причина сбоя V10.6:
V10.6 заменяла resources.arsc таблицей из APK, пересобранного Apktool, но
оставляла старые физические файлы res/ из Xiaomi APK. Таблица и файлы ресурсов
оказались из разных сборок. Поэтому не разрешался XML AppUpgradeProvider.

Что меняется в V10.7:
- сохраняется AndroidManifest.xml оригинала;
- classes.dex берётся побайтно из проверенного V8;
- classes2.dex, assets, библиотеки и остальные нересурсные файлы сохраняются
  из оригинала;
- вместе с пересобранной resources.arsc заменяется весь комплект res/;
- статическая проверка требует, чтобы все пути файловых ресурсов из дампа AAPT2
  реально существовали внутри APK;
- workflow устанавливает APK на Android 15 arm64-эмулятор, запускает приложение,
  проверяет отсутствие ошибки FILE_PROVIDER_PATHS, живой процесс и UI hierarchy;
- APK выдаётся как artifact только вместе с журналами проверок.

Ветка сборки: v10.7-build.
Исходные APK выбираются из origin/v10-build и проверяются по SHA-256.
V10.6 не перезаписывается.

После успешной сборки нужно установить V10.7 на телефон. Подпись генерируется
новая для каждой GitHub Actions сборки; установку поверх предыдущего APK с
другой подписью Android может запретить — тогда удалить предыдущую тестовую
версию перед установкой. Данные приложения при удалении могут потеряться.
