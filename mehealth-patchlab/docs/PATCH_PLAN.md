# План работ

## Этап 1 — базовая инвентаризация
- [ ] Проверить SHA-256 оригинала.
- [ ] Проверить ZIP CRC.
- [ ] Зафиксировать package name, version name/code и подпись.
- [ ] Сохранить перечень файлов APK и языковых ресурсов.
- [ ] Составить отчёт baseline без изменения APK.

## Этап 2 — карта локализации
- [ ] Извлечь `resources.arsc`, `res/values*`, assets и доступные строки из DEX.
- [ ] Определить приоритет источников текста: Android resources, assets, WebView/JS, DEX.
- [ ] Сопоставить китайские строки с экранами приложения.
- [ ] Разделить пользовательские строки и технические значения.

## Этап 3 — патч
- [ ] Создать минимальный patch-set с точным списком замен.
- [ ] Проверить отсутствие потерянных ключей и плейсхолдеров.
- [ ] Сравнить изменённые ресурсы с оригиналом.
- [ ] Пересобрать APK воспроизводимым способом.

## Этап 4 — проверки
- [ ] ZIP/APK integrity.
- [ ] Проверка package/version и подписи.
- [ ] Установка на тестовое устройство.
- [ ] Проверка запуска, навигации и экранов, затронутых переводом.
- [ ] Отчёт с SHA-256 и ограничениями тестирования.

## Критерий выпуска
APK не выдаётся как готовый, если не пройдены структурные проверки и не указано, какие проверки на устройстве реально выполнены.
