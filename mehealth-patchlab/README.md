# MeHealth PatchLab — русификация Xiaomi Health Research 1.4.6

Изолированный проект для исследования и русификации APK `com.mi.healthresearch` версии `1.4.6` методом контролируемого патчинга.

## Цели

1. Зафиксировать оригинальный APK и его контрольную сумму.
2. Извлечь ресурсы и строки, определить, где хранятся видимые китайские надписи.
3. Подготовить русские переводы с сохранением плейсхолдеров, форматирования и технических идентификаторов.
4. Применять только адресные патчи, не менять поведение приложения без отдельного обоснования.
5. Пересобирать, подписывать тестовым ключом и проверять APK структурно и на устройстве.
6. Выпускать APK только после прохождения проверок; хранить отчёт о каждой сборке.

## Исходные данные

- Имя файла в библиотеке: `小米健康研究_1.4.6.apk`
- Пакет: `com.mi.healthresearch`
- Версия: `1.4.6`
- SHA-256 оригинала, зафиксированный в предыдущем forensic-отчёте: `9e872f2d75e4ec1d509216d8caa998c2957d797c57b8ecc1ed8c92054f53c4bc`

Перед использованием файла локально обязательно повторно вычислить SHA-256. Не включать APK в Git: он проприетарный, большой и должен передаваться отдельно.

## Структура

- `docs/` — границы проекта, план и критерии приёмки.
- `patch/` — описание процедуры патчинга.
- `translations/` — перевод и правила проверки строк.
- `tools/preflight.sh` — предварительная проверка APK до анализа/патчинга.

## Первый этап

Сначала провести инвентаризацию APK: SHA-256, ZIP CRC, package/version, список ресурсов, языковые каталоги, DEX и подпись. Затем определить минимально достаточный способ патчинга. Не копировать изменения из проекта Mi Fitness: это отдельное приложение и отдельный проект.

## Правила качества

- Не переводить идентификаторы, имена пакетов, ключи ресурсов и API.
- Не менять `%1$s`, `%d`, `{name}`, HTML/XML-теги, escape-последовательности и порядок аргументов.
- Не удалять оригинальные ресурсы.
- Не заявлять о работоспособности без фактической проверки установки и запуска.
- Каждая версия должна иметь отчёт, SHA-256, список изменённых файлов и результат тестов.
