# Переводы

Переводные таблицы будут добавлены после извлечения фактических строк оригинального APK.

Для каждой строки сохранять:
- ресурсный ключ или точный источник;
- оригинал на китайском;
- русский перевод;
- контекст/экран;
- комментарий о плейсхолдерах и форматировании;
- статус проверки.

До подтверждения контекста не угадывать перевод по одному фрагменту. Имена пакетов, ключи, URL, параметры API и системные значения не переводить.
