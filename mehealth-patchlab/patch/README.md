# Патчинг APK

На первом проходе патч не применять. Сначала зафиксировать исходное состояние и определить точное место хранения каждой пользовательской строки.

Предпочтительный порядок:
1. Android string resources — адресный патч ресурсов.
2. Локализуемые JSON/XML/HTML/JS в assets — патч соответствующего файла с проверкой кодировки.
3. Строки в DEX — только если ресурсного источника нет; патчировать точечно и проверять структуру DEX.
4. Обфусцированные/динамически получаемые строки — исследовать отдельно, не делать массовые замены.

Запрещены глобальные замены без контекста: они могут изменить ключи, URL, значения протокола или логику.
