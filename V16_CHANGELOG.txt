Fixes
1. Recognize generic two/three-letter Android language qualifiers and BCP-47 `b+...` tags rather than relying on the incomplete locale allow-list. Both `values-bo-rCN` and `values-ug-rCN` now route to `values-ru` while non-locale qualifiers remain intact.
2. Reject malformed region-only source qualifiers rather than manufacturing invalid output directories.
3. Add an explicit pre-aapt2 gate to audit all `values-ru*` directories, with a negative test for the exact observed `values-ru-bo-rCN` failure.
4. Fix translation-coverage parsing: aapt2's resource headers do not always include `PUBLIC`; the old parser silently reported zero Chinese strings and a false 0% coverage. V16 parses public and non-public entries and fails if it finds zero default CJK strings.
5. Fix a placeholder-parser false positive: `% s` is not a valid Java Formatter string conversion (Java throws `FormatFlagsConversionMismatchException`). The old regex treated it as a required placeholder and skipped `sport_run_rate_increase_suggestion`. V16 excludes invalid flags for string/character/general conversions and has regression tests for valid `%1$s`, `%2$d`, and `%%` tokens.
6. Version the CI display name, candidate/final artifacts, APK filename and checksum as V16, while retaining the existing `.github/workflows/v13.yml` path and `v13-build` branch to avoid duplicate workflow runs.
7. Harden the Termux applicator: it checks unexpected local changes before cleanup, preserves only known timestamped backups, verifies Python syntax, runs self-tests, checks staged diffs, and pushes only the expected patch files.
